# Тестовое задание для Полигонатора
# Основная логика
Карту решил скопировать оригинальную из пакмена, на ней основывается граф, где вершина это перекрёстки, грани это коридоры, сложность это расстояние, сделано для того, чтоб можно было перекладывать алгоритмы на графе для призраков. Были использованы такие алогоритмы как, Алгоритм Дийскстры, БФС, ДФС, Алгоритм Беллмана Форда
## Призрак дийкстры
Описан в файле DiikstraGhost.cpp 
Ищет кратчайший путь
## Призрак БФС
Описан в файле BfsGhost.cpp
Ищет путь с наименьшим количеством поворотов
## Призрак ДФС
Описан в файле DfsGhost.cpp
Рекурсивный обход в глубину с пометкой посещённых узлов и откатом из тупиков. Находит какой-то путь, не обязательно короткий.
## Призрак Беллмана Форда
Описан в файле BellmanFordGhost.cpp
Призрак предпочитает коридоры с несъеденной едой, туда пакмену ещё предстоит прийти, коридор, полный точек, получает отрицательный вес.

# Отладка
Для удобства отладки сделал у призраков галочку DrawPath. После её включения на экране можно будет увидеть путь призрака до пакмена, и отследить как работают разные алгоритмы
